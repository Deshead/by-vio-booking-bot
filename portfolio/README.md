# BY VIO · страница проекта

Откройте `index.html` двойным щелчком в браузере. Страница адаптируется к телефону; переключатель над макетом показывает экран клиента или мастера.

Для показа заказчику достаточно переслать один файл `index.html`. Шрифты, стили, графика и сценарий переключения встроены; интернет нужен только для перехода в Telegram. Макеты не создают записи. Бот по ссылке отвечает, когда запущен его сервер.

При необходимости сохраните страницу в PDF через «Печать» браузера.
